# Spotify Frontend Clone

A beautiful, responsive Spotify web player clone built with HTML and CSS. This project replicates the modern Spotify interface with a sleek dark theme and intuitive layout.

## Live Demo

Check out the live site: [Spotify Frontend Clone](https://bushrashaikh15.github.io/spotify-frontend/)

## Features

- Clean Spotify-like user interface
- Fully responsive design (works on desktop, tablet, and mobile)
- Hover effects and smooth transitions
- Music player layout (sidebar, main content, player bar)
- Font Awesome icons for professional look
- Dark theme matching Spotify's aesthetic

## Technologies Used

- HTML5 - Semantic structure
- CSS3 - Modern styling with Flexbox and Grid
- Font Awesome - Icons and visual elements
- Google Fonts - Montserrat font family
